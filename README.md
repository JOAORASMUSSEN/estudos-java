# estudos-java

Repositório dedicado aos meus estudos de Java, cobrindo desde a sintaxe básica até Orientação
a Objetos.
## Tecnologias
- Java 17 (ou superior)
- Git & GitHub
- IntelliJ IDEA
## Conteúdos Praticados
Atualmente, o projeto está organizado em pacotes que cobrem:
- **Introdução:** Tipos primitivos, operadores e estruturas condicionais.
- **Estruturas de Repetição:** `for`, `while` e `do-while`.
- **Arrays:** Unidimensionais e Multidimensionais (Matrizes).
- **Orientação a Objetos:** Criação de classes, atributos, métodos e testes (Classes
  `Estudante`, `Carro`, `Calculadora`, `Impressora`).
## Como executar
1. Clone o repositório: `git clone https://github.com/seu-usuario/maratonajava.git`
2. Abra o projeto na sua IDE (IntelliJ recomendada).
3. Localize as classes no pacote `test` e execute o método `main`.
