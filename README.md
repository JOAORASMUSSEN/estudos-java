# estudos-java

Repositório dedicado aos meus estudos de Java, acompanhando o curso **Maratona Java Virado no Jiraya**
## 🚀 Tecnologias
- Java 21
- Git & GitHub
- IntelliJ IDEA

## 📚 Conteúdos Praticados

O projeto está organizado em pacotes com os seguintes tópicos:

- **Introdução:**  
  Tipos primitivos, operadores e estruturas condicionais.

- **Estruturas de Repetição:**  
  `for`, `while` e `do-while`.

- **Arrays:**  
  Arrays unidimensionais e multidimensionais (matrizes).

- **Orientação a Objetos:**  
  - Criação de classes  
  - Atributos e métodos  
  - Instanciação de objetos  
  - Separação em pacotes `dominio` e `test`  
  - Exemplos com as classes: `Estudante`, `Carro`, `Professor`, `Calculadora` e `Impressora`

## ▶️ Como executar

1. Clone o repositório:  
   `git clone https://github.com/joaorasmussen/estudos-java.git`

2. Importe o projeto na sua IDE.

3. Escolha um dos exemplos disponíveis nos pacotes.

4. Execute a aplicação através do método `main`.

## 📌 Observações

- Este repositório é focado em aprendizado e prática.
- Os códigos podem ser atualizados conforme avanço no curso.
